# تطبيق إدارة الحضانة 👶

تطبيق أندرويد (وأيضًا يعمل من المتصفح) لمتابعة الحضانة بالكامل: الأطفال، الحضور، الاشتراكات والمدفوعات، المصروفات، العاملين والرواتب، والتقارير. **كل البيانات محفوظة على الموبايل نفسه** ويعمل بدون إنترنت.

## المميزات

- **الرئيسية**: عدد الأطفال، حضور اليوم، إيرادات ومصروفات وصافي ربح الشهر، إجمالي المتأخرات، قائمة اللي ما دفعوش، أعياد الميلاد، آخر الملاحظات.
- **الأطفال**: صورة، تاريخ الميلاد (والسن يتحسب تلقائيًا)، الفصل، ولي الأمر وتليفوناته، العنوان، الاشتراك الشهري، الملاحظات الصحية والحساسية، الأشخاص المسموح لهم بالاستلام، تاريخ الالتحاق/الترك. بحث وفلترة بالفصل.
- **ملف الطفل**: مدفوعاته، حضوره في الشهر، سجل الملاحظات اليومية، اتصال وواتساب مباشر، ورسالة تذكير بالمصاريف جاهزة على الواتساب.
- **الحضور والغياب**: حاضر / متأخر / غائب لكل طفل، وقت الدخول والخروج، "الكل حاضر" بضغطة، ومشاركة كشف اليوم.
- **الحسابات**:
  - المقبوضات: اشتراك شهري، رسوم تسجيل، زي وأدوات، باص، رحلات… مع طريقة الدفع (نقدي، فودافون كاش، إنستاباي…) وإيصال مرقّم للطباعة أو الإرسال على الواتساب.
  - المصروفات حسب البند: إيجار، رواتب، أكل، كهرباء ومياه، أدوات، صيانة…
  - المستحقات: مين دفع ومين لأ في الشهر، نسبة التحصيل، إجمالي المتأخر على كل طفل، وزر تذكير واتساب.
- **العاملين**: الوظيفة والراتب والتليفون، و"صرف الراتب" يتسجل تلقائيًا كمصروف.
- **الفصول**: اسم الفصل، الفئة العمرية، السعة، المعلمة المسؤولة.
- **التقارير**: إيرادات ومصروفات وصافي أي شهر، رسم بياني لآخر ٦ شهور، توزيع المصروفات والإيرادات، نسبة الحضور، الأطفال الجدد واللي تركوا، وطباعة التقرير.
- **نسخة احتياطية**: تصدير واستيراد كل البيانات في ملف.

## تثبيت التطبيق على الموبايل (APK)

1. كل ما يتعمل push على المستودع، GitHub Actions يبني ملف `nursery-app.apk` تلقائيًا (workflow: *Build Nursery Android APK*).
2. افتح صفحة **Releases** في المستودع من الموبايل وحمّل `nursery-app.apk`.
3. افتح الملف ووافق على "التثبيت من مصادر غير معروفة" لو الموبايل طلب ذلك.

## تجربته من الكمبيوتر

```bash
cd nursery
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## هيكل المشروع

```
nursery/            التطبيق نفسه (HTML / CSS / JavaScript)
  index.html
  css/style.css
  js/db.js          التخزين المحلي (IndexedDB)
  js/app.js         كل الشاشات والمنطق
android/            مشروع أندرويد يعرض التطبيق كـ APK أصلي (WebView) مع طباعة وحفظ ملفات ومشاركة
.github/workflows/android-apk.yml   بناء الـ APK تلقائيًا
```

## مهم

البيانات محفوظة على الموبايل فقط، فاعمل **تصدير نسخة احتياطية** بانتظام (المزيد ← تصدير نسخة احتياطية) واحتفظ بالملف على Google Drive أو الإيميل.
