# تطبيق إدارة مرضى - د. محمد مجدي (استشاري جراحة الصدر)

تطبيق ويب يعمل على الهاتف (Progressive Web App) لتسجيل بيانات المرضى، التاريخ المرضي، الأشعة والصور الطبية، مع اقتراحات مبدئية تساعد في تسريع كتابة الملف الطبي. **كل البيانات تُخزَّن محليًا على الهاتف نفسه** (باستخدام IndexedDB) ولا يتم إرسال أي بيانات لأي سيرفر خارجي، ويعمل التطبيق بدون إنترنت بعد أول تشغيل.

## المميزات

- تسجيل بيانات المريض الأساسية (الاسم، السن، النوع، الهاتف، العنوان، رقم الملف).
- التاريخ المرضي: الأمراض المزمنة، الحساسية، الأدوية الحالية، العمليات السابقة، والتدخين.
- تسجيل الشكوى والتشخيص وملاحظات الطبيب.
- **اقتراحات مبدئية تلقائية** أثناء كتابة الأعراض (مثل ضيق النفس، ألم الصدر، نفث الدم) لتذكير الطبيب بالاحتمالات والفحوصات الشائعة في جراحة الصدر — وهي اقتراحات إرشادية فقط ولا تغني عن التقييم الإكلينيكي.
- رفع وحفظ الأشعة والصور الطبية (X-Ray, CT, MRI, سونار, تقارير) مع إمكانية عرضها وحذفها.
- بحث سريع عن المرضى بالاسم.
- تصدير/استيراد نسخة احتياطية بصيغة JSON لحفظ البيانات أو نقلها لهاتف آخر.
- طباعة ملف المريض.
- يعمل كتطبيق مُثبَّت على الشاشة الرئيسية للهاتف (PWA) ويعمل بدون إنترنت.

## طريقة التشغيل على الهاتف

### الطريقة الأسهل (بدون سيرفر)
افتح ملف `index.html` مباشرة من متصفح الهاتف (Chrome/Safari). التطبيق سيعمل، لكن ميزة "العمل بدون إنترنت" (Service Worker) تحتاج تشغيل الملفات من خلال سيرفر محلي أو استضافة (خطوة تالية).

### الطريقة الموصى بها: استضافة بسيطة ثم تثبيت التطبيق
1. ارفع محتويات المجلد على أي استضافة ثابتة (مثل GitHub Pages، Netlify، Vercel) أو شغّلها محليًا بأمر بسيط:
   ```bash
   python3 -m http.server 8080
   ```
2. افتح الرابط من متصفح الهاتف (Chrome على أندرويد / Safari على آيفون).
3. من قائمة المتصفح اختر **"إضافة إلى الشاشة الرئيسية" / Add to Home Screen**.
4. سيظهر التطبيق كأيقونة مستقلة على الهاتف ويعمل حتى بدون إنترنت، وكل البيانات محفوظة محليًا على نفس الجهاز.

## نسخ احتياطي مهم

نظرًا لأن البيانات محفوظة على الهاتف فقط، يُنصح بشدة بعمل **تصدير نسخة احتياطية** بشكل دوري من قائمة (⋮) أعلى الشاشة، وحفظ ملف الـ JSON الناتج في مكان آمن (بريد إلكتروني، تخزين سحابي)، حتى لا تُفقد البيانات في حال حذف التطبيق أو تغيير الهاتف. يمكن استيراد نفس الملف لاحقًا لاستعادة كل البيانات.

## هيكل المشروع

```
index.html        الصفحة الرئيسية وواجهة المستخدم
css/style.css      التنسيقات
js/db.js           طبقة التخزين المحلي (IndexedDB)
js/app.js          منطق التطبيق ومحرك الاقتراحات
manifest.json      إعدادات تثبيت التطبيق على الهاتف (PWA)
sw.js              Service Worker لتشغيل التطبيق بدون إنترنت
icons/icon.svg     أيقونة التطبيق
```

## ملاحظة طبية

الاقتراحات الظاهرة أثناء كتابة الأعراض هي أداة مساعدة لتنظيم وتسريع كتابة الملف الطبي بناءً على قواعد عامة في جراحة الصدر، وليست تشخيصًا نهائيًا، ويبقى القرار الطبي بالكامل بيد الطبيب المعالج.
